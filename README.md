# Learn Full Stack Development

This repository contains class practice files and assignments for learning core full-stack web development concepts.

## Contents

- HTML practice pages in `html/`
- CSS notes and examples in `css/`
- JavaScript and DOM notes in `js/`
- PHP notes in `php/`
- XML notes in `xml/`
- Assignment markdown in `docs/`

## Folder Structure

- `html/` — all `.htm` practice pages
- `css/` — `css.md`, `tut.css` and other `.htm` pages for learning css.
- `js/` — `js.md`, `dom.md`, `jQuery.md`
- `php/` — `php.md`
- `xml/` — `xml.md`
- `docs/` — `assignment1.md`

## How to use

Open the files directly in a browser or with VS Code Live Server for local learning and practice.
