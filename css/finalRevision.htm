CSS position properties

Static (The default)

  • Logic: Elements follow the normal document flow.
  • Behaviour: Properties like top, bottom, left, right, z-index have no effect.
  • Use case: Resetting a position that was inherited or applied via another class.

Relative

  • Logic: Element positioned relative to its original normal position.
  • Behaviour: Setting top: 20px moves it 20 pixels down from where it should have been. Crucially, the gap where it used to be is preserved, other elements won't move to fill the space.

Absolute

  • Logic: Element is removed from normal document flow
  • Behaviour: Positions itself relative to it;s nearest positioned ancestor (ancestor with any position except static). If no such ancestor exists, uses document body.
  • Use case: Often used inside a position: relative container to pin an icon or a badge to a specific corner.

Fixed

  • Logic: Positioned relative to he viewport (browser window)
  • Behaviour: Stays in exact same spot even when the page is scrolled. Completely removed from document flow.
  • Use case: Navigatin bar or "back to top" buttons.

Sticky

  • Logic: Hybrid of relative and fixed
  • Behaviour: Acts like relative until user scrolls to a threshold.(eg top:0), at which point it acts as fixed inside it's parent container
  • Use case: Resetting a position that was inherited or applied via another class.
